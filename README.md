# eng-mohamed-elsayedahmed.github.io

The front door for https://eng-mohamed-elsayedahmed.github.io/ — a single page
that routes visitors to the portfolio, the CV, and the ways to get in touch.

Because this repository is named after the account, GitHub serves it at the
root of the domain. Every other repository with Pages enabled sits underneath
it, so `/portfolio/` and any future project keep working unchanged.

## Files

- `index.html` — the page
- `style.css` — palette and typefaces follow the portfolio so both read as one identity
- `assets/profile.jpg` — copied from the portfolio repository

## Adding a project

Add one more `.route` block inside the "On this domain" nav in `index.html`.
